# Furkan Yiğit Bakım — Portfolio

This is my personal portfolio website. I built it to introduce myself, share the things I have worked on, and collect my education, experience, activities, and technical interests in one place.

The website is intentionally simple: it is a static HTML and CSS project that can be opened directly in a browser and hosted easily with GitHub Pages. There is no framework or build step behind it.

## What You Can Find Here

- A short introduction and contact links
- My education history and academic achievements
- Experience in software engineering and undergraduate research
- Selected projects with links to their GitHub repositories
- Volunteering, mentoring, and university activities
- A summary of my technical skills and tools

## Built With

- HTML
- CSS
- A small amount of JavaScript for project-card scroll animations
- Font Awesome for interface icons
- Google Fonts for typography

## Project Structure

```text
.
├── index.html
├── style.css
└── assets/
	├── profile.jpg
	├── Furkan_Yigit_Bakim_CV.pdf
	└── portfolio images and institution logos
```

The site uses local assets wherever possible, so the portfolio remains easy to move, open locally, or deploy to another static host.

## Run Locally

No installation is required. Open `index.html` directly in a browser, or use the Live Server extension in VS Code for a local preview.
